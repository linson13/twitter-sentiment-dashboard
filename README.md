An interactive results dashboard for the [Twitter Sentiment Analysis](https://github.com/linson13/twitter-sentiment-analysis)
project — visualizing dataset composition, model performance, and real
predictions from a classifier trained on 67,480 tweets.

**[View the live dashboard →](https://twitter-sentiment-dashboard-nine.vercel.app)**

## What's inside

- **Dataset composition** — label and source breakdown across three
  independently-sourced public tweet datasets
- **Interactive confusion matrix** — a custom hand-built SVG heatmap;
  hover any cell for exact counts and percentages
- **Per-class precision / recall / F1** — chart comparison across
  positive, negative, and neutral
- **Top predictive words per class** — model interpretability, straight
  from the trained coefficients
- **Real sample predictions** — actual tweets from the held-out test
  set, including honest failure cases (not just the wins)

Every number on this page is generated by `export_dashboard_data.py` in
the [analysis repo](https://github.com/linson13/twitter-sentiment-analysis) —
nothing here is hand-typed or hard-coded.

## Run locally

```bash
git clone https://github.com/linson13/twitter-sentiment-dashboard.git
cd twitter-sentiment-dashboard
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

Outputs a fully static site to `dist/` — no backend required.
